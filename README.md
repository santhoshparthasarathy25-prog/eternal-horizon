# Eternal Horizon — Mobile Web App

## Files
- `index.html`: app
- `manifest.webmanifest`: home-screen display metadata

## Install on Android
1. Upload these files to a GitHub repository (keep `index.html` and `manifest.webmanifest` in the repository root).
2. In GitHub, open **Settings → Pages**.
3. Set source to **Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. Open the published HTTPS URL in Chrome on Android.
5. Chrome menu (⋮) → **Add to Home screen** or **Install app**.

## Reference images
In the app, choose two images in this order:
1. Night Beach
2. Milky Way

They are saved in IndexedDB for this browser/site on this device. Browser storage can be cleared by Android/browser cleanup, so keep your originals.

## Notes
- This is a web app, not an APK.
- WebGL2 is required. If you see a graphics error, try an updated Chrome browser and use Battery saver quality.
- The app uses a simplified procedural scene; it does not claim true 8K rendering or guaranteed 60 FPS.
- GitHub Pages repositories are public; do not upload private photos or secrets.
